## Summary
Drynest Smart Appliance & Facility Operations Platform — real-time monitoring dashboard, smart telemetry diagnostics, and predictive maintenance schedules.

## Core Features
*   **Live equipment status:** Real-time monitoring dashboard.
*   **Automated maintenance alerts:** Intelligent notification system.
*   **Energy consumption tracker:** Track and optimize usage.
*   **AI diagnostic assistant:** Smart telemetry diagnostics and troubleshooting.

## Setup Guide
1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the development server:
   ```bash
   npm run dev
   ```
3. Build for production:
   ```bash
   npm run build
   ```
